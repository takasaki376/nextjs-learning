# TASK-018: useRef

## 概要

`useRef`によるDOM参照と、表示に使わない値の保持をToDo登録処理で学ぶ。

## 学習目的

ref更新が再レンダリングを起こさないこと、DOMへの命令的操作を必要最小限に使う方法を理解する。

## 前提

TASK-017完了。実装開始時にReactのバージョンを確認すること（このリポジトリ直下には`package.json`がなく、作成時点では検出不能）。

## 対象URL

`/hooks/use-ref`

## 主な対象ファイル

- `src/app/hooks/use-ref/page.tsx`
- `src/app/hooks/use-ref/components/UseRefTodoDemo.tsx`

## 実装内容

- [ ] 登録後に入力をクリアし、input refから`focus()`する
- [ ] 前回登録したタスクIDをrefへ保存する
- [ ] 比較用にstate版を作り、描画回数を記録する
- [ ] ref更新だけでは画面表示が更新されないことを確認する

## 実装上のポイント

まずstateで前回IDを保持して不要な再レンダリングを確認し、refへ変更する。DOM操作と入力イベントが必要なため該当部分だけClient Componentにする。描画に使う値はstate、描画に不要でレンダー間に保持したい値はrefが候補となる。レンダー中に`ref.current`を読み書きして表示を決めない。

## 業務アプリでの利用例

- 検索フォーム送信後のフォーカス復帰
- タイマーID、前回リクエストID、外部SDKインスタンスの保持
- データグリッドの特定セルへのスクロール
